# iOS 双语与 RDX2 测试版

- 新增简体中文／英文／跟随系统，覆盖界面、权限说明和无障碍文案；切换语言保留连接服务和草稿。
- RDX2 紧凑配对码保留完整邀请和身份公钥；默认地址下 119 字节，固定样本 M 纠错从 81×81 降至 45×45 模块。同一邀请不随倒计时换码。
- 扫码先预览并核验设备公钥，再由用户确认及电脑批准；首次连接与可信重连统一使用 `/relay/{sessionId}`。
- 发布制品以源码 SHA 和 SHA-256 标识，提供直接下载 IPA、双架构 DMG、Windows 安装包和服务器镜像。

这是预发布测试版，不是完整真机验收版本。iPhone 识别速度、真实 E2E／离线语音和 Windows 真机体验仍待用户测试。Mac Debug 当前的系统钥匙串读取阻塞不包含在“汉化完成”的声明内；未删除凭据绕过授权。

IPA 未签名、Mac 包未公证、Windows 包未签名；安装限制见 `INSTALL-TEST.md`。旧手机版本不能识别新的 RDX2 配对码。VPS 不会因本次预发布自动更新。
